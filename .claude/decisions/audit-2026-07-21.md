## Executive Summary — Top 5 Cross-Cutting Risks

1. **Live production secrets are in git history on a public GitHub repo** (security + devops, independently confirmed). JWT signing secret, two Groq API keys, and the Gmail SMTP app password are all recoverable via `git show` from commits `296c523`/`23ba36a`/`6e961a2`/`8258c0f`/`9e07edc` even though the files are now gitignored. The repo (`iamandreearadu/fit-app`) is confirmed **public**. Anyone can forge a valid JWT for any user, including admin. **This must be treated as already compromised.**
2. **`Fix-Release` does not currently compile in production configuration** (performance audit). `npx ng build --configuration production` fails on two template bugs — the branch cannot ship until fixed.
3. **Test coverage is effectively zero at every layer that matters** (test-coverage audit). No backend test project exists at all (0/14 controllers, 0/23 services tested). All 17 frontend specs are unmodified `should create` boilerplate; none of the 13 facades or 14 API services have any spec. Cypress only tests against mocked responses, never the real backend.
4. **There is no deployment path from a fresh clone to a running instance** (devops audit) — this is the direct root cause of today's startup incident (missing `appsettings.json`/`environment.ts`, no template, no CI secret injection).
5. **Retention has no outbound arm** (UX + product audits, independently converged). Streaks and the "at risk" banner are fully built server-side but only reach a user already inside the app — nothing emails or pushes a lapsing user back, despite MailKit/SignalR already being wired.

## Overall Verdict

**❌ Not production-ready.** In priority order:

1. **Today, independent of everything else:** rotate the JWT secret, both Groq API keys, and the Gmail app password — they are confirmed exposed in a public repo's git history. This is an active security incident, not a backlog item.
2. **Before any release:** fix the two production-build errors (findings #4–5) — the branch cannot currently be deployed at all.
3. **Before any release:** fix the `BlogService.DeleteAsync` FK crash (#6) and the `WorkoutsTabFacade` silent error-swallowing (#7) — both are live, reachable bugs, not theoretical.
4. **Before scaling users:** close the deployment gap (#3) so a fresh clone/CI can actually stand up the app without secret archaeology.
5. **Before scaling users:** stand up backend tests starting with ownership/cross-user-isolation checks (#8, #11–14) — currently a regression here would silently leak one user's health data to another with nothing to catch it.
6. **Before pushing growth:** ship the streak-defense reminder (#30) — the cheapest, highest-leverage fix in the entire audit, reusing infrastructure that already exists.
7. **Ongoing:** `SocialService` decomposition (#25), `any` cleanup (#23), CLAUDE.md doc-sync (#35) — real debt, not urgent.
